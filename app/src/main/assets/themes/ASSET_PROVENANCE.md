# Theme Asset Provenance

The production theme plates and character cutouts in this directory were generated with OpenAI's built-in `imagegen` tool on 2026-10-06 and then cropped and optimized locally for Android delivery.

The source prompts intentionally request original, grounded painterly-realism artwork. They do not name or imitate a living artist, franchise, brand, or protected character. No third-party source image was used.

Runtime roles:

- backgrounds provide environment depth only;
- transparent cutouts remain separate participant/prop layers;
- financial state, fill geometry, contribution paths, particles, and settlement effects remain runtime-generated;
- procedural fallbacks remain available if an asset cannot be decoded.

The exact final generation prompts are documented in `IMAGEGEN_PROMPTS.md` at the repository root; delivery constraints remain in `ART_ASSET_SPEC.md`.
