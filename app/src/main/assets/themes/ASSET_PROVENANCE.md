# Theme Asset Provenance

The production theme plates and character cutouts in this directory were generated with OpenAI's built-in `imagegen` tool and then optimized locally for Android delivery.

The Woodland pack was regenerated on 2026-11-04 as original kawaii storybook game art: one environment plate, eight transparent character cutouts, a transparent savings-stump container, and separate acorn/walnut collectibles. The source prompts do not name or imitate a living artist, franchise, brand, or protected character. No third-party source image was used.

Runtime roles:

- backgrounds provide environment depth only;
- transparent cutouts remain separate participant/prop layers;
- financial state, fill geometry, contribution paths, squash/bounce motion, particles, and settlement effects remain runtime-generated;
- procedural fallbacks remain available if an asset cannot be decoded.

The exact final generation prompts are documented in `IMAGEGEN_PROMPTS.md` at the repository root; delivery constraints remain in `ART_ASSET_SPEC.md`.
